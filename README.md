# Etiel Mining Hub

Industrial equipment ordering platform (customer store). Backend: Supabase. Frontend: Next.js.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — redirects to `/en`. Amharic: `/am`.
